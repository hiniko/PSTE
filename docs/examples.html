“Repair”

runbookThe Apache Cassandra projectApache-2.0source
Before
There are 2 types of repairs: full repairs, and incremental repairs. Full repairs operate over all of the data in the token range being repaired. Incremental repairs only repair data that's been written since the previous incremental repair.
After
Cassandra has 2 types of repair: full repair and incremental repair. A full repair covers all of the data in the token range that it repairs. An incremental repair covers only the data that Cassandra wrote after the previous incremental repair.

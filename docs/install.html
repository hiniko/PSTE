Install

How to get PSTE, what it turns on, and what it costs in context.

Install through the plugin marketplace

PSTE is a plugin for Claude Code. The repository is also a plugin marketplace, so two commands install it. Run them inside Claude Code:

/plugin marketplace add hiniko/PSTE
/plugin install pste@hiniko

The first command adds the marketplace. The second installs the plugin from it. To get a later version, run /plugin marketplace update.

What the plugin carries

The plugin carries the skill, the /pste command, and two hooks. The hooks keep the rules active across a long session.

Install the skill by hand

You can also install the skill by hand. Clone hiniko/PSTE. Then copy skill/ into your Claude Code skills directory as pste/. The path ends pste/SKILL.md.

Turn it on

Once the skill is active, run /pste on or /pste off. There is one standard, and every rule in it applies.

What PSTE costs in context

PSTE runs as a Claude Code plugin. Loading its rules costs context space, not money. This repository has no tokenizer, and will not add one, so the table below reports characters. A character count is exact. A token count would be an estimate.

What loads, and whenCharacters
The skill's description, at every session start428
skill/SKILL.md, when the skill fires16,617
The per-turn reminder, added by the UserPromptSubmit hook574
skill/SKILL.md again, written by the SessionStart hook16,617

Claude Code loads a skill's description at session start, and loads the skill's body only when the skill fires. So a session that never uses PSTE pays 428 characters, not 16,617.

The plugin's SessionStart hook writes the whole of skill/SKILL.md into context anyway, on purpose. The hook's own comment gives the reason: a short summary decays over a long session, and compaction can remove it, but the full rule set survives both. A session that also triggers the skill can hold the rule set twice.

Every turn after that carries the 574-character reminder from the UserPromptSubmit hook. This keeps the rules in view without repeating the full text on every turn.

This cost exists because the skill also governs a whole conversation, an experimental use that Validation measures.

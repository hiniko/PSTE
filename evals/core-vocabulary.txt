# PSTE core vocabulary list
#
# Used by evals/readability.py to compute the share of words that a reader can be
# expected to know (Nation 2006; Laufer and Ravenhorst-Kalovski 2010).
#
# PROVENANCE. This list is original, and the editors built it by hand in two parts:
#
#   1. General core English: the function words and the highest-frequency content
#      words of everyday English.
#   2. Technical core: the words that software prose needs, and that a general
#      list leaves out.
#
# The list carries no frequency data and copies no corpus. It names words that a
# reader with basic English and some exposure to software is likely to know. It is
# a floor, not a ceiling: the checker also counts every word that PSTE-1 approves
# and every term that terms.yaml defines, so a technical reader is not penalised
# for knowing `container` or `commit`.
#
# The list is deliberately generous. A word here does not become approved for
# writing. Appendix A decides that. This file only decides what counts as known
# when the checker measures coverage.
#
# One word per line. A line that starts with # is a comment.
